# Contributing to Postiz Libre

## Before You Start

**Try upstream first.** This fork exists only because `gitroomhq/postiz-app` systematically
ignores community PRs (see [FORK-README.md](FORK-README.md) and [UPSTREAM-ISSUES.md](UPSTREAM-ISSUES.md) for evidence).

1. Open your PR on `gitroomhq/postiz-app`
2. Wait a reasonable time (30 days) or until it is clear the PR is ignored/closed without merit
3. Then open an issue here referencing your upstream PR
4. We will review and merge

## Why This Rule?

We do not want to fragment the ecosystem. If upstream starts accepting community contributions
again, this fork will happily become obsolete.

## Technical Workflow

See [FORK-GIT-WORKFLOW.md](FORK-GIT-WORKFLOW.md) for the complete Git workflow.

Quick start:

- Fork this repo
- Create a branch `feat/your-feature` from `main`
- Rebase on `main` before opening a PR to `dev`
- Follow the existing code style
